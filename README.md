# سوق أزهري الذكي

منصة سوق إلكترونية عربية مدعومة بالذكاء الاصطناعي: تساعد المشتري على إيجاد المنتج المناسب، وتساعد البائع على إدارة متجره بذكاء.

هذا المستودع هو مصدر البرنامج. الخطة الكاملة للمشروع — الفكرة، المستخدمون، الشاشات، المعمارية، ومراحل البناء — موجودة هنا:

**[خطة البرنامج](docs/خطة-المشروع.md)**

## ماذا يبني المشروع؟

- سوق تصفح وشراء يعمل بدون الاعتماد على الذكاء الاصطناعي.
- مساعد عربي يفهم طلب المشتري ويرشّح من الكتالوج الحقيقي فقط.
- أدوات للبائع: نشر منتج، مخزون، طلبات، وتوليد وصف.
- لوحة إدارة لمراجعة المتاجر والمحتوى.

## مراحل التنفيذ

| المرحلة | الناتج |
| --- | --- |
| 0 الأساس | تصفح، سلة، وطلب تجريبي |
| 1 سوق يعمل | بائع ومشتري يكملان دورة بيع |
| 2 الذكاء | بحث دلالي، مساعد، وتوصيات |
| 3 النمو | دفع إلكتروني، تقييمات، وثقة المنصة |

التفاصيل والقرارات المفتوحة في وثيقة الخطة.

## الحالة الحالية

المشروع في مرحلة التخطيط. لم يبدأ تنفيذ التطبيق بعد. بعد اعتماد الخطة نبدأ بالمرحلة 0.
